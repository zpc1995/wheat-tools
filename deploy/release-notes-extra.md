## wheat tools（麦工具）

一个纯前端的小工具集合：**31 个工具**，覆盖 JSON/YAML/Markdown 处理、
编解码与哈希、时间与定时表达式、二维码、单位与颜色、HTTP 与网络诊断等。

设计上坚持三点：

- **本地优先**——除「外网 IP 查询」需要访问第三方接口外，所有计算都在浏览器里完成，
  输入内容不会离开页面。这一点在工具内部也写明了，而不是只放在文档里。
- **不猜**——遇到无法等价转换或无法判断的情况（例如 cron 与 systemd 对
  「星期 + 日期」的并集/交集差异、CORS 失败的真实原因），工具会说明做不到什么，
  而不是给出一个看起来对的错误答案。
- **可验证**——每个工具都配有单元检查（合计 1600+ 项断言），
  其中不少是用权威实现交叉验证的：MD5 对照 RFC 1321 官方向量、
  正则速查表逐条真正编译、JSON Schema 用 ajv 回灌样本、
  systemd 转换与 `systemd-analyze` 的实际触发时刻逐次比对。

### 下载

- **`wheat-tools-v0.1.0.zip`** —— 构建好的静态站点，解压即可部署，
  不需要 Node 或 pnpm。包内有 `部署说明.txt`。
- GitHub 自动提供的 `Source code` 压缩包是源代码，需要自行
  `pnpm install && pnpm build`。
